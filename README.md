# So7obDash

لوحة خاصة لمتابعة مشاريع GitHub من مكان واحد، بواجهة عربية. يعرض التطبيق التجريبي بيانات اصطناعية فقط. يتطلب الوضع الحي تطبيق GitHub بصلاحيات قراءة وتثبيتاً على المستودعات المختارة. لا ينشئ So7obDash قضايا أو طلبات دمج، ولا ينفّذ نشرًا من GitHub.

## التشغيل المحلي

المتطلبات: Node.js 24 وnpm. من جذر المشروع:

```bash
npm ci
npm run check
npm run build
SO7OB_MODE=demo npm start
```

افتح http://127.0.0.1:3086. لا تحتاج بيانات الدخول إلى GitHub في الوضع التجريبي. لا تجعل النسخة التجريبية واجهة بديلة عند تعطل الوضع الحي.

## التشغيل الحي

اقرأ [دليل التشغيل](docs/operations.md) وراجع [نموذج الإعداد](.env.example). شغّل Node على عنوان محلي خلف وكيل HTTPS، وحدّد `PUBLIC_ORIGIN` بدقة، وجهّز ملف مفتاح التطبيق وكلمة مرور المالك وبيانات التثبيت أولاً. لا تضع أسرار التشغيل في المستودع أو في متغيرات Vite التي تصل إلى المتصفح.

### نطاق البيانات

يفصل النموذج بين المشروع بوصفه وحدة متابعة، والمستودع بوصفه مصدر بيانات. اختَر المستودعات صراحةً عند تثبيت تطبيق GitHub. لا يعني عدم وجود قضايا مفتوحة أن المشروع مكتمل، ولا يعني انعدام وصول المنظومة إلى مصدر ما أن قيمته صفر. لا تعمم حالة اختبار أو إصدار على مشروع كامل بلا دليل.
